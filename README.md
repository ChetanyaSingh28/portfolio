# Personal Portfolio

Welcome to the repository for my personal portfolio! I am a computer science student based in India, and this project serves as a central hub to showcase my technical skills, software development projects, and design work.

## 🚀 Tech Stack

This project is a [Next.js](https://nextjs.org/) application bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app). It leverages modern web development tools:

* **Framework:** Next.js
* **Language:** TypeScript
* **Typography:** `next/font` for automatically optimizing and loading the Geist font family.
